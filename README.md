
# Interactive Rating Component

This is my solution to the Interactive Rating Component challenge from Frontend Mentor.

## Live Demo

[View Live Site](https://interactive-rating-component-theta-six.vercel.app/)

## Overview

Users can select a rating from 1 to 5 and submit their feedback. After submitting, a thank-you message displays the selected rating.

### Features

- Select a rating from 1 to 5.
- Highlight the selected rating.
- Interactive hover and focus states.
- Display the selected rating on the thank-you screen.
- Responsive layout for mobile and desktop screens.
- Built with semantic HTML and JavaScript.



## Built With

- HTML5
- Tailwind CSS v4
- JavaScript
- Vite
- Google Fonts — Overpass
- Vercel (Deployment)

## What I Learned

While building this project, I practiced:

- Selecting HTML elements with `querySelector()` and `querySelectorAll()`.
- Handling click events with `addEventListener()`.
- Using `forEach()` to work with multiple rating buttons.
- Updating CSS classes with `classList.add()` and `classList.remove()`.
- Storing the selected rating using a JavaScript variable.
- Updating text with `textContent`.
- Showing and hiding sections using Tailwind CSS utility classes.
- Building and deploying a Vite project.

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/md-nurun-nobi/interactive-rating-component.git
   ```

2. Navigate to the project folder:

   ```bash
   cd interactive-rating-component
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
